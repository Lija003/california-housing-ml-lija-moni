## How to Run
1. Clone this repository.
2. Make sure `housing.csv` is in the same folder as the notebook.
3. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
4. Open `California_Housing_Price_Prediction.ipynb` in Jupyter or Google Colab and run all cells.

## Files
- `California_Housing_Price_Prediction.ipynb` — full notebook (EDA, cleaning, modeling, evaluation, prediction demo)
- `summary.md` — one-page written summary of approach, results and limitations
- `housing.csv` — dataset
